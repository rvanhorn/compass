# Publishing checklist

Add this file after [the showcase](feature-guide.md) in the builder. Choose combined output to try file ordering and cross-document navigation.

## Start with a document

This heading intentionally repeats a heading from the showcase. Combined documents should keep distinct anchors so each chapter remains easy to navigate.

- [ ] Put the chapters in the intended order.
- [ ] Choose a title and subtitle for the combined document.
- [ ] Confirm that local images appear.
- [ ] Follow the link to the showcase's [interactive tables](feature-guide.md#interactive-tables).

## Review the export

| Check | Status | Notes |
| --- | --- | --- |
| Document title | Partly | Set a title that describes the whole publication |
| Navigation | Partly | Try Contents, outline, Find, and section links |
| Images | Partly | Check local assets in each chapter |
| Print | Partly | Review print preview for long tables |

> [!TIP]
> Save the builder project so you can reuse the file order and appearance settings.

## Share

Export the HTML and open it independently of the builder. The layout and controls travel with the file. Mermaid, MathJax, and remote assets can still need internet access.

Return to [the showcase](feature-guide.md#make-it-yours) to keep exploring.
